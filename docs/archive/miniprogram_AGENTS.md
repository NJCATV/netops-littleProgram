# AGENTS.md

## 项目名称

江苏有线南京分公司智维助手

## 项目定位

面向江苏有线南京分公司内部网络运维、装维、工程支撑人员的微信小程序工具助手。

## 技术栈

- 微信小程序原生开发
- WXML / WXSS / JavaScript / JSON
- TDesign Miniprogram
- 不使用云开发
- 不接后台
- 不接数据库
- 不实现真实登录鉴权

## 视觉风格

- 参考传统网络设备网管系统
- 极简、克制、工程化
- 灰白黑蓝灰为主
- 不做营销页、大屏风格、玻璃拟态、强渐变、大圆角、花哨图标

## 目录规范

- `pages` 放页面
- `components` 放通用组件
- `utils` 放工具函数
- 水印绘制、定位、权限等逻辑必须拆到 `utils` 中
- 页面 JS 不要堆积重复逻辑

## 开发原则

- 每个阶段完成后必须 `git commit`
- 每个阶段完成后必须 `git push` 到远程仓库
- 不要一次性做无关功能
- 不要擅自引入大型框架
- 不要实现用户没有要求的复杂功能
- 不要破坏已有页面结构
- 修改前先看现有代码
- 每次提交前检查 `git status`

## 小程序后续扩展原则

- 每新增一个工具，独立页面
- 工具入口统一放在便捷工具页
- 通用 UI 抽成 `components`
- 通用能力抽成 `utils`
- 后续登录注册可以独立阶段实现，不要提前写死假鉴权
